# Student Performance Analyzer

## About the Project

Student Performance Analyzer is a beginner-friendly Python application that calculates and analyzes student examination marks.

It generates a report containing total marks, average, percentage, highest marks, lowest marks, grade, and pass/fail status.

## Features

* Accepts student names and subject marks.
* Supports a user-defined number of subjects.
* Calculates total and average marks.
* Calculates the percentage obtained.
* Identifies the highest and lowest marks.
* Assigns grades based on predefined thresholds.
* Checks whether the student passes every subject.
* Validates marks and handles invalid numeric input.

## Technologies Used

* Python
* Python functions
* Lists and loops
* Conditional statements
* Exception handling

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python student_analyzer.py
```

If necessary, try:

```bash
py student_analyzer.py
```

## Grading Rules

This project uses illustrative grading thresholds:

* A: Average >= 90
* B: Average >= 75
* C: Average >= 60
* D: Average >= 40
* F: Average < 40

For this version, a student passes only if every subject mark is at least 35 out of 100.

These rules can be modified to match a particular institution's requirements.
